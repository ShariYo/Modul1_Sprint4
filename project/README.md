
# Covid-19 crisis at South Korea

This project is about Covid-19 crisis at South Korea. Analysis of various given datasets, plotting results and giving better insights of data.  
At this project some of the questions will be tried to answer, i.e. where virus spread was most active?; What's the Case Fatality Rate (CFR) between various age groups?; Is the virus spread between gengers was similar?; etc.  
All the answers will be based on a given datasets, regrouped or remaked tables, plots.


## Data source

Given data source can be found at Kaggle with the link provided below:

```bash
  https://www.kaggle.com/datasets/kimjihoo/coronavirusdataset
```
